# QA-2 Engine - Intelligent Q&A Assistant

This is the standalone configuration for deploying the QA-2 web interface to Hugging Face Spaces. It uses a lightweight FastAPI server to serve pure HTML, CSS, and JS. 

The `shared/` directory contains global theme assets mapped locally to satisfy Hugging Face Docker sandboxing.
